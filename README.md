# Juliane Leal Rodrigues

Landing page afetiva e responsiva dedicada a Juliane Leal Rodrigues, construída com HTML, CSS modular e JavaScript em módulos.

## Recursos

- tema claro e escuro com preferência persistida;
- navegação responsiva;
- carrossel de momentos;
- seção de culinária com galeria sanfonada acessível;
- seção de frases e poemas;
- galeria com oito retratos e lightbox nativo;
- animações de entrada com respeito a `prefers-reduced-motion`;
- conteúdo editorial em português.

As imagens principais são servidas em WebP para reduzir o tempo de carregamento em dispositivos móveis.

## Estrutura

- `index.html`: estrutura e conteúdo da página;
- `assets/css/`: tokens, estilos base, layouts e componentes;
- `assets/js/`: inicialização e módulos de comportamento;
- `assets/images/`: imagens e recursos visuais.

## Execução local

Sirva a pasta com um servidor HTTP local e abra o `index.html`. Os módulos JavaScript e o Swiper são carregados diretamente pelo navegador.
